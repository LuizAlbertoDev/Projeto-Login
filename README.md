# Projeto Login — página responsiva

Exercício de HTML e CSS com layout responsivo de formulário de login, utilizando fontes e ícones do Material Symbols.

## Tecnologias

- HTML5
- CSS3
- Media queries
- Google Material Symbols

## Estrutura

```text
Projeto-Login/
├── index.html
├── estilos/
│   ├── style.css
│   └── media-query.css
└── imagens/
```

## Como executar

Abra `index.html` no navegador. Não são necessárias dependências de build.

## Limitações

O projeto demonstra **a interface** de login. O formulário aponta para `login.php`, que não está presente neste repositório; portanto, não realiza autenticação real. O link de recuperação de senha também é apenas ilustrativo.

## Objetivo de aprendizagem

Praticar formulários HTML, campos acessíveis, organização de CSS e adaptação da página para diferentes tamanhos de tela.
